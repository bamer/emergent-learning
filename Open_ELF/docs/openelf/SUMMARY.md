## Quick Start

To get started with OpenELF:

1. **Install Dependencies**: Ensure OpenCode server is running
2. **Configure Agents**: Place agent files in appropriate directories
3. **Start Orchestrator**: Run the orchestrator service
4. **Monitor Status**: Use dashboard or API to monitor agents

## Key Features

- **Dual Format Support**: Works with both ELF and OpenCode agent formats
- **Intelligent Orchestration**: Advanced agent lifecycle management
- **Flexible Configuration**: Easy customization and extension
- **Rich API**: REST and WebSocket interfaces for integration
- **Extensible Design**: Plugin system for adding new capabilities

## System Requirements

- OpenCode server (latest version)
- Python 3.8+
- SQLite 3.24+
- 4GB RAM minimum (8GB recommended)
- 10GB disk space for logs and database

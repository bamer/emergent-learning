## H-102: Always update the changelog with every evolution made

**Confidence**: 1.0
**Source**: observation
**Created**: 2026-02-10

Document all changes, decisions, and progress as work continues. This creates a complete audit trail and prevents knowledge loss. Update: IMMEDIATELY after completing task; Format: Structured entries with date, description, and impact; Location: Project root CHANGELOG.md; Scope: Code changes, architectural decisions, bug fixes, feature additions, meetings, approvals

# OpenELF Plugin System Documentation

Welcome to the OpenELF (OpenCode Emergent Learning Framework) Plugin System documentation. This document provides a comprehensive overview of the enhanced integration between the ELF orchestrator and OpenCode's native agent system.

## Overview

OpenELF bridges the sophisticated agent orchestration capabilities of the Emergent Learning Framework with OpenCode's native agent management system. This integration provides:

- **Best of Both Worlds**: Powerful orchestration with easy configuration
- **Flexible Agent Management**: Support for both ELF and OpenCode agent formats
- **Extensible Architecture**: Easy addition of skills, plugins, and new agents
- **Seamless Integration**: Transparent handling of different agent formats

## Key Features

### 1. Dual Agent Format Support
Support for both ELF and OpenCode agent formats with configurable precedence.

### 2. Enhanced Personality Management
Extended personality system with skills, plugins, and tools support.

### 3. Flexible Model Selection
Intelligent model selection based on agent type, task complexity, and user preferences.

### 4. Sophisticated Orchestration
Advanced agent lifecycle management, health monitoring, and automatic recovery.
